# Image-processing-and-computer--vision-lab
-> Introduction

This repository contains a collection of Image Processing Lab Experiments implemented using Python and OpenCV. The experiments are designed to help students understand basic to advanced image processing concepts such as image acquisition, enhancement, filtering, and transformation.

-> Objectives

To understand the fundamentals of digital image processing.

To learn how to capture, read, and manipulate images using Python.

To implement common image processing techniques.

To gain practical experience with OpenCV and NumPy libraries.

-> Tools & Technologies Used

Programming Language: Python 3.x

Library: OpenCV (cv2)

Supporting Library: NumPy

IDE: Visual Studio Code (VS Code)

Operating System: Windows
